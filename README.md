## 🚀 CÁCH SỬ DỤNG

### Cách 1: Chạy Trực Tiếp (Nhanh Nhất)

**Bước 1: Clone repo**
```bash
git clone https://github.com/YOUR_USERNAME/trợ-lý-ai.git
cd trợ-lý-ai
```

**Bước 2: Cài đặt thư viện**
```bash
pip install -r requirements.txt
```

**Bước 3: Chạy app**
```bash
streamlit run app.py
```

**Bước 4: Mở trình duyệt**
```
http://localhost:8501
```

### Cách 2: Dùng Online (Không Cần Cài)

**Deploy lên Streamlit Cloud:**

1. Đẩy code lên GitHub (như ở trên)
2. Truy cập: https://share.streamlit.io
3. Click "New app"
4. Chọn repo + `app.py`
5. Deploy!

👉 Bạn bè sẽ có link để dùng mà không cần cài gì!
